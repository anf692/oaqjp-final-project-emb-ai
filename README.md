
# Final project

## Project Name
Final project - Emotion Detection Application

## Description
This project consists of developing an AI-powered web application that detects emotions in text using IBM Watson Natural Language Processing (NLP).

The application analyzes a given text and identifies the following emotions:
- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion expressed in the text.

## Technologies Used
- Python
- Flask
- IBM Watson NLP
- Requests
- Unittest
- Pylint

## Project Objectives
- Develop an emotion detection application using Watson NLP.
- Format the emotion detection results.
- Package the application as a Python module.
- Implement unit tests.
- Deploy the application using Flask.
- Handle errors and invalid inputs.
- Perform static code analysis.
